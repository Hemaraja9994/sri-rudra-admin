# Claude/Codex UI Prompt

Redesign this clinic website to look premium, trustworthy, modern, and medical-professional.

Use:
- Tailwind CSS design tokens
- shadcn/ui components
- Motion/Framer Motion for subtle animations only
- Responsive layout
- Soft medical palette: white, teal, cyan, slate, warm accent
- Large hero section with trust badges
- Card-based services
- Before/after style visual hierarchy
- Consistent 8px spacing system
- Rounded-2xl cards, soft shadows, subtle gradients
- No loud colors, no clutter, no generic stock-heavy look

Create:
1. A premium hero section
2. Sticky glass navbar
3. Service cards with icons
4. Doctor/clinic trust section
5. Testimonials
6. FAQ accordion
7. CTA section with WhatsApp/call buttons
8. Footer with clinic details

Do not randomly restyle each section. Create a consistent design system first, then apply it everywhere.

Commands:
```bash
npx shadcn@latest init
npx shadcn@latest add button card accordion badge avatar
npm install motion lucide-react
```
